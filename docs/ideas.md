# 今後の検討事項

メンバーの意見を要約した企画検討用メモです。個人名・発言全文は掲載していません。以下は採用・実装が決まった内容ではありません。

- 初見で目的が分かりにくく、操作と結果のつながりが弱い。体験前後に何が変わるかを伝える方法を検討する。
- スマホで、目的・操作対象・結果を同じ画面に見せる体験構成を検討する。
- 地球を撮影し、その操作で撮った写真を地上へ届ける体験を検討する。
- 願いの紙を画像データにし、衛星へ載せる過程を連続した体験として見せる案を検討する。
- 模擬地上局から架空の衛星経由で指令を送り、扇風機が動く体験を検討する。
- メイン／サブの役割分担、AIによる説明や操作の補助を検討する。
- Three.js、Remotion、実機連携は未採用。移管初版では追加しない。

移管初版の変更は見た目・入口・公開に必要な調整です。体験のルール変更や新しい撮影・送信・実機制御は、意見を集めた後に個別に検討します。
