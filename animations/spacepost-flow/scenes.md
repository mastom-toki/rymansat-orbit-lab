# 宇宙ポストの旅：家族向けの場面構成

小学生・中学生、保護者、高齢者が同じイベントで見ることを想定したレビュー版。24秒・1080×1440・無音。生成した背景を使わず、短冊・写真・カメラ・SDカード・衛星・ロケット・地球を独立した物として配置する。

| 秒 | 画面の主役 | 動作と結果 |
|---|---|---|
| 0–2.5 | 大きな短冊とえんぴつ | 冒頭から書く。0.7秒程度で例文が見え、結果を保持 |
| 2.5–5.5 | 元の紙、カメラ、同じ紙の写真 | 0.3秒から撮影、短い移動で写真が生まれる。元の紙は机に残す |
| 5.5–8 | 写真とSDカード | 同じ写真が0.8秒程度でSDカードに入り、画像として保存された状態を見せる |
| 8–10.5 | SDカードと衛星 | SDカードを衛星へ動かす。中の画像を説明用の窓で見せる |
| 10.5–13.5 | ロケット | 画像を載せた衛星が中にあることを見せ、短く上昇する |
| 13.5–16 | 放出される衛星 | ロケットの先端が開き、衛星が大きく離れる |
| 16–20 | 地球と衛星 | 周回を実際に動かす。写真の入った同じ衛星を追う |
| 20–24 | 大気圏に入る衛星と光跡 | 衛星が消え、光の跡を見せる。最後は「宇宙へいくのは、短冊の画像」を保持 |

一画面の主な動作は一つ。場面が変わると配置・主役・背景も切り替える。短い動作と、結果を読む間を分ける。一定速度の長い移動、開始前の静止待ち、暗い写実的な背景の細部、装飾的な英語は入れない。主要文字は大きい日本語とし、説明は短くする。

絵は透明背景の個別素材4点（カメラ、衛星、ロケット、地球）を内蔵画像生成で作成。短冊の文と星印はコードで固定し、同じ描画から写真を1回作る。写真は全場面で同じ画像を使い、色だけでなく紙／写真のラベルと形で区別する。自由文・受付・個人情報入力は追加しない。

slide-hubのMotion.scenesで場面時刻、Motion.seg／easeで動作、Motion.lerpで座標を計算する。content.jsonを読み、build.mjsでdeck.htmlを組み立てる専用デッキ。テンプレート検討ではexplainerとmaking-of-skitを確認したが、数値解説や制作コメディの演出は今回は使わない。既存テンプレートや共有ランタイムは改変しない。runtimeのコピーをそのまま埋め込む。

意図的な表現：場面の境界はカット。紙と空、打上げと宇宙を一枚の背景で混ぜない。撮影の「パシャ」は文字と短い線で示し、白フラッシュを使わない。衛星内部・ロケットの窓・放出・軌道・再突入は仕組みの模式表現であり、実物や実際の時間・距離・軌道の再現ではない。

初期停止。再生・一時停止・前後の場面・最初へ・時間スライダー・動き低減に対応する。動き低減の場面送りは各場面の結果へ移動し、最終場面も完了状態を見せる。文章版にも全8工程を残す。

説明の参照：https://www.rymansat.com/spacepost 。元のポスターの画像は使用しない。PR #2で宇宙ポストの主画面へ組み込む。公開版は承認・マージ後に反映する。


## ORBIT LABへの組み込み

ホーム→宇宙ポスト→3つの既定例文の選択→本デッキの埋め込みへ進む。URLには例文の番号だけを渡す。flow-content.jsはcontent.jsonの固定配列から文面を選び、任意の文やHTMLは採用しない。写真は選んだ短冊から一度作り、各場面で同じCanvas画像を描く。文字数に合わせて短冊の文字を収める。

埋め込み時はスマホで図と操作が同時に見える高さへ調整する。文章を展開した場合や文字拡大時はスクロールを許す。画面の再描画・移動時に再生を止め、完了は現在の同一オリジンのiframeからだけ受理する。

主操作は350ms以内の連打を1操作とする。場面送りは結果の時点に移動するため、演出を見続けることは通過条件にならない。全体設定・端末設定による動き低減をプレイヤー内で解除できない。最初の場面に戻って前ボタンが無効になる場合は次ボタンへ、最後の場面で次が無効になる場合は最初へボタンへフォーカスを移す。
