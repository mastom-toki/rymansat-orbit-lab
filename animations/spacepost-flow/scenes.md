# 宇宙ポスト：画像データの旅（レビュー版）

先に固定した構成。40秒・1080×1440・無音。ポスターの8工程を参考に独自の図形で描く。ポスター画像の切り貼りはしない。

| 秒 | メッセージ | 主役と遷移 |
|---|---|---|
| 0–4 | 短冊に願いを書く | 例文の紙と鉛筆。以後、紙の原本は地上の定位置に残る |
| 4–9 | 短冊を写真にする | カメラの走査線。紙とは別に、同じ文・星・番号01の画像を作る |
| 9–13 | 画像をSDカードへ | 画像が縮小してSDカードの窓へ入る |
| 13–17 | SDカードを衛星へ | SDカードを衛星へ移し、透視窓で画像01を見せる |
| 17–22 | ロケットで宇宙へ | 同じ衛星をロケット内に収め、上昇。原本の紙は地上に残す |
| 22–26 | 衛星を放出する | フェアリングが左右へ開き、同じ衛星が離れる |
| 26–34 | 地球のまわりを回る | 地球を中心に周回し、軌道を概念的に縮める |
| 34–40 | 大気圏に入り、光る | 衛星の光跡と消失。最終画面は1.5秒以上保持 |

主役の画像データは常に同じ例文・星印・番号01で追跡できる。原本と画像の複製は別オブジェクト。切替で紙そのものを宇宙に動かさない。SDカード・衛星・ロケットは説明用の独自図案であり、実機や実際の搭載方法の再現ではない。距離・時間・大きさ・軌道・再突入は模式化する。明滅・白フラッシュ・音・ループ再生は使わない。

既存テンプレートの固定3工程や箇条書きでは、8工程をまたぐ同じ画像の移動を表現しにくいため、Canvasと時刻指定の描画を使う。slide-hubのMotionランタイムは未改変で埋め込み、補間関数を使用する。自動再生を強制しない独自プレイヤーを付ける。

再生、一時停止、前後の工程、時間スライダー、最初へに対応。初期状態は停止。動き低減設定では工程送りを優先し、自動再生しない。`?t=秒`は書き出し用の停止画面。すべての状態はseek(t)で直接再現できる。

流れの参照：[宇宙ポスト公式](https://www.rymansat.com/spacepost)。添付ポスターは構成の参照のみ。公式ロゴ・写真・人物画は使用していない。
