# ORBIT LAB

リーマンサットの展示企画を検討するための体験デモです。メンバーにスマホで試作を触ってもらい、意見を集めることを目的としています。企画・デザイン・技術構成は未確定で、展示への採用も未定です。実際の宇宙ポストの投函受付・送信・搭載は行いません。

## 試す

- 公開先: https://mastom-toki.github.io/rymansat-orbit-lab/
- リポジトリ: https://github.com/mastom-toki/rymansat-orbit-lab
- 体験: 衛星ミッションメーカー / 宇宙ポスト・お願いごとの旅

ログイン、APIキー、個人情報入力は不要です。部品・電力・重さ・運用判定は架空のルールです。表示の約90秒・約60〜90秒は目安で、実測値ではありません。おすすめの写真コースは電力不足で停止しません。

## ローカルで起動

`index.html` と同じフォルダのCSS・JavaScriptだけで動く静的デモです。HTTPで確認する場合は、このリポジトリのルートで次を実行してください。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

同じPCで http://127.0.0.1:8000/ を開きます。停止は Ctrl+C。ビルド・依存パッケージのインストールは不要です。GitHub Pagesはmainのルートを配信し、`.nojekyll`で静的ファイルをそのまま公開します。mainの更新が公開に反映されます。

## 体験改善

おすすめコースでは、カメラを載せて構図を指・左右ボタン・矢印キーで動かし、模擬写真を撮ります。「地上へ送る」で、その写真と同じ画像が地上側に表示されます。撮り直すと別の構図を作れます。従来の3目的・部品・電力判定は「もっと工夫する」に残しています。

宇宙ポストでは、選んだ例文カードを紙・画像の複製・衛星のメモリ・地球周回・最終章で追えます。元の紙を残して画像を作り、クイズは任意の補足に変更しました。操作と結果をつなぐため、初版の「操作・判定を維持する」範囲をこの2点で変更しています。撮影・通信・軌道は模擬体験で、実際の衛星とは接続しません。

ブラウザ内だけで画像を生成します。外部API・AI・新しいフレームワーク・バックエンドは使いません。

```powershell
node scripts/test-experience.cjs
```

画像生成と進行の自動確認です。画面・操作の確認結果は[検証記録](docs/verification.md)、実機確認は[約3分のチェックリスト](docs/device-checklist.md)を参照してください。ブランチの改修は、承認後にmainへ取り込み、Pagesで公開されます。

## 意見と共同開発

意見はIssuesの「体験への意見」フォームへお願いします。GitHubアカウントがないメンバーからは、通常のチーム内の方法で意見を集めます。デモの閲覧にGitHubアカウントは不要です。個人情報や実際の願いごとはIssueに書かないでください。

初回公開後の変更はブランチを作り、PRで内容と画面・操作の確認結果を共有してからmainに取り込みます。例: `codex/improve-home`。画面サイズによる確認と実機確認を分けて記録します。メンバー招待は、所有者がアカウントを指定してから行います。

改善案は [docs/ideas.md](docs/ideas.md) にまとめています。Three.js、Remotion、実機連携、API、ログイン、収集用バックエンドは未採用です。
