# ORBIT LAB

リーマンサットの展示企画を検討するための体験デモです。メンバーにスマホで試作を触ってもらい、意見を集めることを目的としています。企画・デザイン・技術構成は未確定で、展示への採用も未定です。実際の宇宙ポストの投函受付・送信・搭載は行いません。

## 試す

- 公開先: https://mastom-toki.github.io/rymansat-orbit-lab/
- リポジトリ: https://github.com/mastom-toki/rymansat-orbit-lab
- 体験: 衛星ミッションメーカー / 宇宙ポスト・お願いごとの旅 / 衛星、うまく飛び出せるかな？

ログイン、APIキー、個人情報入力は不要です。部品・電力・重さ・運用判定は架空のルールです。表示の約90秒・約60〜90秒は目安で、実測値ではありません。おすすめの写真コースは電力不足で停止しません。

## ローカルで起動

HTML・CSS・JavaScript・画像素材で動く静的デモです。HTTPで確認する場合は、このリポジトリのルートで次を実行してください。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

同じPCで http://127.0.0.1:8000/ を開きます。停止は Ctrl+C。ビルド・依存パッケージのインストールは不要です。GitHub Pagesはmainのルートを配信し、`.nojekyll`で静的ファイルをそのまま公開します。mainの更新が公開に反映されます。

## 体験改善

おすすめコースでは、カメラを載せて構図を指・左右ボタン・矢印キーで動かし、模擬写真を撮ります。「地上へ送る」で、その写真と同じ画像が地上側に表示されます。撮り直すと別の構図を作れます。従来の3目的・部品・電力判定は「もっと工夫する」に残しています。

宇宙ポストでは、選んだ例文カードを紙・画像の複製・衛星のメモリ・地球周回・最終章で追えます。元の紙を残して画像を作ります。現在の宇宙ポストは、例文選択から24秒・8場面のアニメーションへ進みます。クイズは進行条件にしていません。操作と結果をつなぐため、初版の「操作・判定を維持する」範囲をこの2点で変更しています。撮影・通信・軌道は模擬体験で、実際の衛星とは接続しません。

模擬写真と短冊の画像はブラウザ内だけで生成します。カメラ・衛星・ロケット・地球の静止素材4点は事前に画像生成で作成した独自図案です。閲覧時の外部API・AI・新しいフレームワーク・バックエンドは使いません。

```powershell

```

写真の構図・送信・連打ガードの16シナリオと、宇宙ポストの完了通知・再挑戦・画面移動・動き低減連携の7シナリオを確認します。画面・操作の確認結果は[検証記録](docs/verification.md)、実機確認は[約3分のチェックリスト](docs/device-checklist.md)を参照してください。ブランチの改修は、承認後にmainへ取り込み、Pagesで公開されます。

## 体験03：衛星、うまく飛び出せるかな？

ホームの3つ目、または `#release` から遊ぶタイミングゲームの試作です。「打ち上げる」→しま模様の帯を狙って「衛星を放つ」→結果→「もう一度打ち上げる」。通常は1回約10秒、ゆっくりモードは約13秒です。狙う帯は再挑戦ごとに変わります。成功すると中心からの差で60〜100点。挑戦回数・成功回数・最高点は画面内だけで保持し、再読み込みや画面移動で消えます。

早すぎると大気へ戻って燃え尽き、適切なタイミングなら地球周回、遅いと漂流・月・太陽の創作ルートへ進みます。放さないと時間切れです。**軌道計算ではありません。実際には高度・速度・向きが重要で、放出が遅いだけで月や太陽へ向かうわけではありません。** 画面にもこの区別を表示します。参考：[ESA Types of orbits](https://www.esa.int/Enabling_Support/Space_Transportation/Types_of_orbits)。

HTML/CSS/Canvasだけで描画し、画像の追加読み込み・外部ライブラリ・AI・音声・通信・保存はありません。一時停止、画面非表示時の停止、結果演出スキップ、ゆっくりモード、端末・全体・画面内設定による動き低減に対応します。ボタンはEnter/Spaceで操作でき、キーリピート・300ms未満の連打を抑えます。低減中もタイミング計器は進みます。文字拡大では親ページを縦にスクロールでき、埋め込み高さは内容に追従します。

```powershell
node scripts/test-release-game.cjs
```

判定境界・フレーム間隔・中断再開・再挑戦・連打・完了・フォーカス・メッセージ照合を確認します。ブラウザ確認と実機未検証事項は[検証記録](docs/verification.md)を参照してください。変更の検証対象commitと公開状況は検証記録に分けて記載します。

## 追加試作：3D写真ミッション

ホームの「3Dの衛星を触る」、または `/#cubesat3d` から操作できます。mainに取り込まれた版がGitHub Pagesへ反映されます。ローカル確認も同じ入口を使います。ES ModulesとWebGL 2を使うため、file URLでの起動には対応しません。

指のドラッグ・矢印ボタン・矢印キーで立体の衛星を回し、カメラを取り付け、衛星の向きで決まった構図をPNGに撮影します。「地上へ送る」で同一画像を受信側に表示し、撮り直しで別の向きを試せます。地球を見失ったら「地球を向く」で戻れます。既存3体験と任意の部品・電力コースは維持しています。

衛星・カメラ・地球は説明用の独自図案です。実機・軌道の再現、端末カメラの使用、実際の通信・受付は行いません。写真は子画面内のメモリに保持し、移動・再読み込みで消えます。動き低減、装着・送信のスキップ、画面移動時の中断に対応します。WebGL表示に失敗した場合は、読み直すか既存の写真体験へ進めます。

Three.js **0.186.1 / MIT** を同梱し、この試作を開いた時だけ読み込みます。配布JSは約2.12MB（非圧縮）。ビルド・npm install・CDN・外部APIは不要です。ライセンスと配布物ハッシュは [vendor/three/provenance.json](vendor/three/provenance.json) と [LICENSE](vendor/three/LICENSE) にあります。待機中は連続描画を止め、離脱時はGPUリソースを解放します。OPPO Reno11 Aで起動・回転・撮影・受信を確認しました。現在の端末設定（幅320 CSS px・文字倍率1.15）では主要操作に縦スクロールが必要です。読込時間・発熱の定量測定とSafari対応は未検証です。

```powershell
node scripts/test-cubesat-3d.cjs
node scripts/test-cubesat-camera.mjs
node scripts/test-experience.cjs
node scripts/test-spacepost-flow.cjs
node scripts/test-release-game.cjs
```

状態テストでは撮影を模擬し、姿勢計算テストでは同梱のThree.jsを使用します。実描画と同じ画像の受信はブラウザで別に確認します。採用した移管元HTML v0.1およびSites現行版との同一性未確認という記録は変更しません。確認範囲は[検証記録](docs/verification.md)、実機での約3分の確認は[チェックリスト](docs/device-checklist.md)を参照してください。
