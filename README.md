# ORBIT LAB

リーマンサットの展示企画を検討するための体験デモです。メンバーにスマホで試作を触ってもらい、意見を集めることを目的としています。企画・デザイン・技術構成は未確定で、展示への採用も未定です。実際の宇宙ポストの投函受付・送信・搭載は行いません。

## 試す

- 公開先: https://mastom-toki.github.io/rymansat-orbit-lab/
- リポジトリ: https://github.com/mastom-toki/rymansat-orbit-lab
- 体験: 衛星ミッションメーカー / 宇宙ポスト・お願いごとの旅

ログイン、APIキー、個人情報入力は不要です。部品・電力・重さ・運用判定は架空のルールです。表示の約90秒・約60〜90秒は目安で、実測値ではありません。おすすめの写真コースは電力不足で停止しません。

## ローカルで起動

HTML・CSS・JavaScript・画像素材で動く静的デモです。HTTPで確認する場合は、このリポジトリのルートで次を実行してください。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

同じPCで http://127.0.0.1:8000/ を開きます。停止は Ctrl+C。ビルド・依存パッケージのインストールは不要です。GitHub Pagesはmainのルートを配信し、`.nojekyll`で静的ファイルをそのまま公開します。mainの更新が公開に反映されます。

## 体験改善

おすすめコースでは、カメラを載せて構図を指・左右ボタン・矢印キーで動かし、模擬写真を撮ります。「地上へ送る」で、その写真と同じ画像が地上側に表示されます。撮り直すと別の構図を作れます。従来の3目的・部品・電力判定は「もっと工夫する」に残しています。

宇宙ポストでは、選んだ例文カードを紙・画像の複製・衛星のメモリ・地球周回・最終章で追えます。元の紙を残して画像を作ります。現在の宇宙ポストは、例文選択から24秒・8場面のアニメーションへ進みます。クイズは進行条件にしていません。操作と結果をつなぐため、初版の「操作・判定を維持する」範囲をこの2点で変更しています。撮影・通信・軌道は模擬体験で、実際の衛星とは接続しません。

模擬写真と短冊の画像はブラウザ内だけで生成します。カメラ・衛星・ロケット・地球の静止素材4点は事前に画像生成で作成した独自図案です。閲覧時の外部API・AI・新しいフレームワーク・バックエンドは使いません。

```powershell
node scripts/test-experience.cjs
```

写真の構図・送信・連打ガードの16シナリオと、宇宙ポストの完了通知・再挑戦・画面移動・動き低減連携の7シナリオを確認します。画面・操作の確認結果は[検証記録](docs/verification.md)、実機確認は[約3分のチェックリスト](docs/device-checklist.md)を参照してください。ブランチの改修は、承認後にmainへ取り込み、Pagesで公開されます。

## 宇宙ポスト：24秒・8場面

ホームの「旅をはじめる」から例文を選ぶと、短冊を書く→写真にする→SDカードへ保存→衛星へ搭載→打上げ→放出→地球周回→再突入へ進みます。選んだ文面と星印を同じ写真として引き継ぎ、紙の原本は地上に残します。初期停止で、再生・一時停止、前後の場面、最初へ、時間スライダー、動き低減、文章版を用意しています。

```powershell
node scripts/test-spacepost-flow.cjs
```

8場面・721時点の状態、3例文の一致、無効な入力の拒否、動き低減とフォーカス、連打ガードを検査します。模擬衛星の内部・時間・距離・軌道の再現精度は保証しません。理解しやすさ・面白さ・適切なテンポは、初見の人の操作で別途確認します。

描画は既存のHTML/CSS/Canvasと、slide-hubのMotion.scenes／seg／ease／lerpを使用。動画生成AI、Three.js、Remotionは使っていません。静止素材の生成記録は[prompts.md](animations/spacepost-flow/prompts.md)、8場面の時刻表は[scenes.md](animations/spacepost-flow/scenes.md)にあります。

動き低減は、全体設定・端末設定・プレイヤー内設定のいずれかがオンなら適用します。読み込みが終わるまで再生操作を待たせ、移動時は停止します。埋め込みの連絡は同じオリジンの現在の画面からだけ受け付けます。外部フレーム、通信API、保存、実際の受付は追加していません。

静的な単独確認は[deck.html](animations/spacepost-flow/deck.html)。`?t=12.5`で任意時刻に停止、`?wish=0`〜`?wish=2`で既定例文を選択できます。自由文は受け付けません。ソースを変更したら `node animations/spacepost-flow/build.mjs` で配信用HTMLを再生成します。Node.jsは制作・テスト時だけ必要で、公開サイトのビルドは不要です。
